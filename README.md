# אפליקציית נוכחות

אפליקציית ווב מתקדמת (PWA) לדיווח נוכחות: כניסה/יציאה, דיווח היעדרות (חופשה/מחלה) בלוח שנה, השלמת נוכחות ידנית, וצפייה בדוחות חודשיים.

**שלב נוכחי:** רק אפליקציית המשתמש, ללקוח אחד (ללא מסך ניהול, ללא ריבוי לקוחות עדיין — אבל מבנה הנתונים כבר כולל `client_id` כדי שיהיה קל להוסיף הפרדה בין לקוחות בהמשך).

## מבנה טכני

- **שרת:** Node.js + Express
- **בסיס נתונים:** SQLite מובנה ב-Node (`node:sqlite`, מגרסה 22+) — קובץ יחיד ב-`data/attendance.db`, לא דורש התקנה נוספת.
- **צד לקוח:** HTML/CSS/JS פשוט, RTL, בעברית, בנוי כ-PWA (ניתן להתקנה על המסך הראשי בנייד).

## הרצה על המחשב (בדיקה ראשונה)

```bash
npm install
npm start
```

השרת יעלה על `http://localhost:3000` (אפשר לשנות פורט עם `PORT=3001 npm start`).
פתחו את הכתובת בדפדפן Chrome/Edge. מומלץ לבדוק גם במצב תצוגת מובייל של הדפדפן (F12 → Toggle device toolbar) כדי לראות איך זה נראה בטלפון.

הפעולות שאפשר לבדוק:
- לחיצה על "כניסה" / "יציאה" בעמוד הראשי.
- "דיווח היעדרות" — לחיצה על יום בלוח השנה מאפשרת לסמן חופשה/מחלה עם הערה.
- "השלמת נוכחות" — לחיצה על יום מציגה את הדיווחים הקיימים ומאפשרת להוסיף/למחוק כניסה או יציאה ידנית.
- "צפייה בדיווחים" — לוח שנה עם סה"כ שעות ליום; לחיצה על יום מציגה את הכניסות/יציאות של אותו יום.

## התקנה על טלפון אנדרואיד (שלב הבא)

כדי שתוכלו להתקין את האפליקציה כ"אפליקציה" על המסך הראשי בטלפון:

### אופציה א' — בדיקה מהירה באותה רשת WiFi
1. ודאו שהמחשב והטלפון מחוברים לאותה רשת WiFi.
2. במחשב, מצאו את הכתובת המקומית שלו: `ipconfig` (חפשו שורת "IPv4 Address", למשל `192.168.1.23`).
3. הריצו את השרת: `npm start`.
4. בטלפון, פתחו Chrome וגשו לכתובת `http://<כתובת-IP-של-המחשב>:3000`.
5. בתפריט של Chrome (שלוש נקודות) בחרו **"הוספה למסך הבית" / "התקנת אפליקציה"**.

הערה: בגלל שזו כתובת HTTP רגילה (לא HTTPS), אנדרואיד עדיין יאפשר "הוספה למסך הבית" אבל חלק מיכולות ה-PWA (כמו Service Worker מלא) עובדות בצורה מלאה רק דרך `localhost` או HTTPS. זה מספיק לבדיקה, אבל לא לשימוש קבוע.

### אופציה ב' — פרסום זמני עם HTTPS (מומלץ לבדיקה נוחה יותר)
כלים כמו `ngrok` נותנים לשרת המקומי כתובת HTTPS זמנית שנגישה מכל מקום:
```bash
npx ngrok http 3000
```
תקבלו כתובת כמו `https://xxxx.ngrok-free.app` — פתחו אותה בטלפון (בכל רשת, לא רק WiFi משותף) ובצעו "הוספה למסך הבית".

### לשימוש קבוע (לא רק בדיקה)
כשנרצה שהאפליקציה תהיה זמינה כל הזמן (גם כשהמחשב כבוי), נעלה את השרת לאירוח קבוע עם HTTPS — למשל Render / Railway / Fly.io (יש להם שכבה חינמית שמספיקה לשלב הזה). זה גם הצעד הדרוש לפני שנבנה את אתר הניהול, כי גם הוא יזדקק לאותו שרת.

### בהמשך — אפליקציה "אמיתית" בחנות
כשנרצה גרסה מותקנת דרך Google Play / App Store (ולא רק "הוספה למסך הבית"), נעטוף את אותה אפליקציית ווב עם [Capacitor](https://capacitorjs.com/) — זה לא דורש כתיבה מחדש של הקוד, רק הוספת שכבת עטיפה native. זה השלב שיאפשר גם iPhone.

## מה עוד לא נבנה (בכוונה, לשלבים הבאים)
- מסך ניהול (Admin) להקמת לקוחות ועובדים.
- התחברות/משתמשים מרובים ללקוח אחד.
- הפרדה לוגית מלאה בין כמה לקוחות (הבסיס קיים בסכמה, אבל אין עדיין UI/הרשאות לכך).
