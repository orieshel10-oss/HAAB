# אפליקציית נוכחות

אפליקציית ווב מתקדמת (PWA) לדיווח נוכחות: כניסה/יציאה, דיווח היעדרות (חופשה/מחלה) בלוח שנה, השלמת נוכחות ידנית, וצפייה בדוחות חודשיים.

**שלב נוכחי:** רק אפליקציית המשתמש, ללקוח אחד (ללא מסך ניהול, ללא ריבוי לקוחות עדיין — אבל מבנה הנתונים כבר כולל `client_id` כדי שיהיה קל להוסיף הפרדה בין לקוחות בהמשך).

**הכתובת החיה (פרוס ב-Render, מחובר ל-Neon):** https://haab-attendance.onrender.com — אפשר לפתוח בטלפון ולבצע "הוספה למסך הבית".

## מבנה טכני

- **שרת:** Node.js + Express
- **בסיס נתונים:** PostgreSQL (מיועד לרוץ מול [Neon](https://neon.tech) — שכבה חינמית, ללא צורך בהתקנת שרת בסיס נתונים משלכם).
- **צד לקוח:** HTML/CSS/JS פשוט, RTL, בעברית, בנוי כ-PWA (ניתן להתקנה על המסך הראשי בנייד).

## הרצה על המחשב (בדיקה ראשונה)

צריך קודם בסיס נתונים (חינמי): עקבו אחרי [ההוראות להקמת Neon](#הקמת-בסיס-נתונים-ב-neon) למטה, ואז:

```bash
copy .env.example .env
# ערכו את .env והדביקו את מחרוזת ההתחברות מ-Neon בתוך DATABASE_URL

npm install
npm start
```

השרת יעלה על `http://localhost:3000` (אפשר לשנות פורט עם `PORT=3001 npm start`, או ע"י הוספת `PORT=3001` לקובץ `.env`).
פתחו את הכתובת בדפדפן Chrome/Edge. מומלץ לבדוק גם במצב תצוגת מובייל של הדפדפן (F12 → Toggle device toolbar) כדי לראות איך זה נראה בטלפון.

הפעולות שאפשר לבדוק:
- לחיצה על "כניסה" / "יציאה" ושעון דיגיטלי בעמוד הראשי.
- "עדכון נוכחות" — לוח שנה שמראה עיגול צבעוני (כחול=חופשה/כנס, אדום=מחלה ומשפחה) ושעות ליום; לחיצה על יום פותחת טופס לבחירת סוג (נוכחות/חופשה/מחלה/מחלת ילד/מחלת בן זוג/כנס), סימון "יום שלם", ושעות כניסה/יציאה.
- "גליון מנותח" — טבלת שעות חודשית לפי חוק (רגילות/125%/150%/שבת) כולל היעדרויות.

## התקנה על טלפון אנדרואיד (שלב הבא)

כדי שתוכלו להתקין את האפליקציה כ"אפליקציה" על המסך הראשי בטלפון:

### אופציה א' — בדיקה מהירה באותה רשת WiFi
1. ודאו שהמחשב והטלפון מחוברים לאותה רשת WiFi.
2. במחשב, מצאו את הכתובת המקומית שלו: `ipconfig` (חפשו שורת "IPv4 Address", למשל `192.168.1.23`).
3. הריצו את השרת: `npm start`.
4. בטלפון, פתחו Chrome וגשו לכתובת `http://<כתובת-IP-של-המחשב>:3000`.
5. בתפריט של Chrome (שלוש נקודות) בחרו **"הוספה למסך הבית" / "התקנת אפליקציה"**.

הערה: בגלל שזו כתובת HTTP רגילה (לא HTTPS), אנדרואיד עדיין יאפשר "הוספה למסך הבית" אבל חלק מיכולות ה-PWA (כמו Service Worker מלא) עובדות בצורה מלאה רק דרך `localhost` או HTTPS. זה מספיק לבדיקה, אבל לא לשימוש קבוע.

### אופציה ב' — פרסום זמני עם HTTPS (מומלץ לבדיקה נוחה יותר)
כלים כמו `ngrok` נותנים לשרת המקומי כתובת HTTPS זמנית שנגישה מכל מקום:
```bash
npx ngrok http 3000
```
תקבלו כתובת כמו `https://xxxx.ngrok-free.app` — פתחו אותה בטלפון (בכל רשת, לא רק WiFi משותף) ובצעו "הוספה למסך הבית".

### לשימוש קבוע (לא רק בדיקה)
כשנרצה שהאפליקציה תהיה זמינה כל הזמן (גם כשהמחשב כבוי), נעלה את השרת לאירוח קבוע עם HTTPS — ההוראות המלאות לכך נמצאות בהמשך המסמך, בסעיפים "הקמת בסיס נתונים ב-Neon" ו-"פריסת השרת ל-Render".

### בהמשך — אפליקציה "אמיתית" בחנות
כשנרצה גרסה מותקנת דרך Google Play / App Store (ולא רק "הוספה למסך הבית"), נעטוף את אותה אפליקציית ווב עם [Capacitor](https://capacitorjs.com/) — זה לא דורש כתיבה מחדש של הקוד, רק הוספת שכבת עטיפה native. זה השלב שיאפשר גם iPhone.

## הקמת בסיס נתונים ב-Neon

[Neon](https://neon.tech) הוא שירות PostgreSQL בענן עם שכבה חינמית שמספיקה לשלב הזה לגמרי.

1. היכנסו ל-[neon.tech](https://neon.tech) והירשמו (אפשר עם חשבון Google/GitHub).
2. לחצו **"Create a project"**. תנו לו שם (למשל `attendance-app`), ובחרו אזור קרוב (למשל Frankfurt / eu-central-1).
3. אחרי שהפרויקט נוצר, לחצו על **"Connect"** (או "Connection Details") בדשבורד.
4. ודאו שהבחירה היא **"Pooled connection"** (מומלץ לשרתים כמו Render), והעתיקו את מחרוזת ההתחברות — נראית כך:
   ```
   postgresql://user:password@ep-xxxxx-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
5. שמרו אותה בצד — תצטרכו אותה גם ל-`.env` המקומי וגם ל-Render.

חשוב: אל תשתפו את המחרוזת הזו בשום מקום ציבורי (יש בה סיסמה). קובץ `.env` כבר מוגדר ב-`.gitignore` כך שלא ייכנס בטעות ל-git.

## פריסת השרת ל-Render

1. וודאו שהקוד נמצא בריפו ב-GitHub (אם עדיין לא: צרו ריפו חדש ב-GitHub והעלו אליו את `attendance-app` עם `git push`).
2. היכנסו ל-[render.com](https://render.com) והירשמו (אפשר עם GitHub).
3. לחצו **"New +"** → **"Web Service"**, ובחרו את הריפו של הפרויקט מ-GitHub.
4. הגדרות השירות:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free מספיק לשלב הזה.
5. בלשונית **"Environment"**, הוסיפו משתנה סביבה:
   - `DATABASE_URL` = מחרוזת ההתחברות מ-Neon (מהסעיף הקודם).
6. לחצו **"Create Web Service"**. Render יתקין את התלויות, יריץ את השרת, וייתן כתובת קבועה כמו:
   ```
   https://attendance-app-xxxx.onrender.com
   ```
7. פתחו את הכתובת הזו בטלפון (מכל רשת, לא רק WiFi משותף) ובצעו "הוספה למסך הבית" — עכשיו זה יעבוד גם כשהמחשב שלכם כבוי.

✅ **השלב הזה כבר בוצע לפרויקט הזה** — השירות פרוס ורץ בכתובת https://haab-attendance.onrender.com (Render service בשם `haab-attendance`, מחובר לריפו `orieshel10-oss/HAAB`, ענף `master`).

**הערה חשובה על השכבה החינמית של Render:** שירות בשכבה החינמית "נרדם" אחרי כמה דקות של חוסר פעילות, וההפעלה הראשונה אחרי שינה כזו לוקחת כ-30-50 שניות. זה תקין לשלב בדיקות, אבל לשימוש יומיומי רציני כדאי לשקול שדרוג לתוכנית בתשלום של Render בהמשך.

**הערה על אבטחה:** בשלב הזה אין עדיין התחברות/הרשאות באפליקציה — כל מי שיש לו את הכתובת יכול לצפות ולערוך את נתוני הנוכחות. זה מקובל לשלב הבדיקות הפנימי, אבל לפני שימוש אמיתי מול עובדים נצטרך להוסיף מנגנון התחברות (זה נכנס לתכנון של אתר הניהול בהמשך).

## מה עוד לא נבנה (בכוונה, לשלבים הבאים)
- מסך ניהול (Admin) להקמת לקוחות ועובדים.
- התחברות/משתמשים מרובים ללקוח אחד.
- הפרדה לוגית מלאה בין כמה לקוחות (הבסיס קיים בסכמה, אבל אין עדיין UI/הרשאות לכך).
